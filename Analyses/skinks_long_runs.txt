# Longer skink analyses, run with run_all.sh:
#   Analyses/run_all.sh --runs Analyses/skinks_long_runs.txt
# (or run_all_rev.sh, to work from the other end on a second computer).
#
# The skink runs in paper_runs.txt did not converge (the largest split R-hat between
# replicates was 1.17-1.88): with the corrected sampler the chains take a long time to
# find the partition in which the ND1 third codon positions have a tree length of their
# own, and that tree length was held down by the old upper bound of 50 (now 1000; see
# src/ParameterTreeLength.cpp). The same 28 settings as in paper_runs.txt, each with a
# 1,000,000-cycle burn-in (so the chain can find that partition before sampling) and
# 10,000,000 cycles sampled every 500 (20,001 samples, as in the original runs). The
# output goes to Analyses/Output/empirical/skinks_long/.
